# Рацион

Личный трекер питания (Android, Capacitor). Правила для агентов и вся документация: `AGENTS.md`, `docs/`.

- `project/` — рабочий проект (код `src/`, Android `apk/`, инструменты `tools/`).
- Релизы приложения: https://github.com/godoffear/racion-app/releases
- В корне лежит старый сайт-PWA (версия 5.34): `index.html`, `sw.js`, `manifest.webmanifest`, иконки. Он отдаётся на godoffear.github.io/racion и приложению не нужен.
- Локально (вне git): `_archive/` (старое), `ready-apk/` (готовые APK), `data-copy/`, `keys-backup/`.
