# Рацион (папка racion-v2)

Локальное приложение для Android: данные только на телефоне, связи с «Тренером» нет. Копия и перенос данных — файлом («Ещё → Копия и перенос данных»). Интернет нужен только для «Проверить обновление» и (по желанию) отправки автокопии на GitHub.

- `src/` — исходники (app.js, foods.js, native.js, v2.js, head.html, меню). Сайт-сборка: `python3 src/build.py` → `index.html`.
- `design/` — иконки (`make_plates.py` → `icons2/`, сейчас выбрана №3), палитры `palettes.json` (по умолчанию «Лес»).
- `apk/` — проект Capacitor/Android. Свои классы: `RacionNativePlugin` (виджет, файлы, обновления), `RacionWidget`.
- Сборка: `./tools/build_apk.sh [номер иконки] [icons2|icons]` → `out/Racion-X.apk`. Нужны JDK 21 (`brew install openjdk@21`), Android SDK, Node. APK подписывается ключом `~/.android/debug.keystore` — его нужно сохранять, иначе обновления поверх не встанут.
- Напоминания: за 30 минут до каждого приёма (+ пт 9:05 взвешивание, вс 20:30 итоги недели).

## Выпуск обновления
1. Правки в `src/` (и `NATIVE_API` в `src/native.js` +1, если нужен новый нативный код).
2. `./tools/make_release.sh 6.2 "Что нового" [номер NATIVE_API, по умолчанию 1]` → папка `release/v6.2/` (APK, `app.html`, `notes.txt`).
3. Публикация: https://github.com/godoffear/racion-app/releases/new — тег `v6.2`, текст из `notes.txt` (первая строка `native:N`), приложить `app.html` и APK, «Latest». Сделано через Chrome-расширение.
4. В приложении «Ещё → Приложение → Проверить обновление»: если `native` не выше установленного — ставится сразу сама (подменяется app.html); иначе скачивается APK и открывается установщик Android (одно подтверждение).

Проверка в WebView эмулятора: `node tools/cdp.js "<js>"` (эмулятор с `-gpu host`).

## Автокопия
Каждый вечер в 23:59: файл `Загрузки/Рацион/Рацион_авто_ДАТА.json` (хранятся 14 последних) и, если подключён токен, отправка в приватный репозиторий `godoffear/racion-backups` (`latest.json` + `history/racion_ДАТА.json`). Токен создаёт сам пользователь: «Ещё → Копия и перенос данных → Подключить отправку на GitHub».
