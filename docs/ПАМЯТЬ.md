# Рацион — подробная память по функциям (читать, когда задача касается нужного куска)

Вынесено из CLAUDE.md, чтобы новая сессия не читала всё подряд. Ищи нужное по ключевому слову (`grep -n "Фасовка" docs/ПАМЯТЬ.md`).

## Как устроено приложение — подробности по версиям
- Заготовки (вкладка, `vPrep`, `prepModel`): большая — в понедельник вечером после GO! на неделю Вт–Пн (`prepCycle`: в пн — следующая неделя): мясо и рыба по подписанным пакетам (Вт/Ср холодильник, дальше морозилка), рис партией от `RICE_MIN`=300 г сухого с запасом в морозилке (`S.riceBank`, сухой эквивалент), яйца — вареных в холодильнике не больше `EGG_BOX`=20 (`S.boiled`, сырые не ограничены, в блюдах из `RAWE` яйца сырые), тофу, овощи, консервы. «Каждый вечер» (Вт–Вс): пакеты на завтра из морозилки, доварить яйца, когда кончаются, батат к завтраку, в вс — «Что дома». Галочки — `S.prepDone[неделя]`; при отметке риса/яиц обновляются `S.riceBank`/`S.boiled`, исходное состояние хранится в `_rice`/`_bo`, чтобы план недели не пересчитывался. На «Сегодня» — короткая карточка дел на вечер.
- `guard` спрашивает «Продукты уже куплены?» только для будущей недели; отметки `S.done` и правки хранятся 120 дней (серия до 119 дней); карточка «Проверь меню» в «Меню» — только Сб–Пн.
- В «Плане дня» все приёмы свёрнуты (`openDone`), кнопки ± пишут в `S.edits`, переключатель веса готового — `S.cooked` + `COOKED`.
- Покупки: список на следующую неделю меню = потребность − остатки (`S.left`, с вычетом того, что съестся до вторника) с округлением до шага `shop`. Запасы (`BULK`) — постоянные переключатели «Есть/Нет» в `S.stock` (1 = нет дома → в списке; «Куплено» возвращает «Есть»). Названия на ценниках — поле `vi` в `PR`, отделы GO! — `SECS`.
- Вкладка «Покупки» (5.5): сверху одна карточка «Купить» — по отделам, крупные строки с галочкой, итог ≈ ₫; всё остальное («Что дома», «Подстроить», ручная правка, запасы, подробный список с ценами) — в свёрнутой «Дома, запасы, цены». Пока «Что дома» не внесено — видно только «Шаг 1».
- Неделя 6–12 окт 2026 (5.7) пересобрана по чеку GO! 5 окт и тому, что было дома: все приёмы в `OVERRIDES` (последний элемент массива приёма — id блюда, `ovItems`/`ovDish`), блюда недели в конце `RECIPES` (с бёдрами — без приёмов `[]`, чтобы не предлагались в другие недели). Разовые задачи «Заготовок» на неделю (лишнее филе ~1,7 кг, джекфрут, тофу — в морозилку) — `PREP_EXTRA`. Раньше неделя была собрана из того, что было дома, остатки дома занесены один раз (`HOME_SEED`, `seedHome`, флаг `S.seed1`, «Подстроить» для этой недели выключен).
- «Что дома» голосом: поле в «Покупках» (`homePanel`), Андрей диктует или вставляет строку `ДОМА: курица 300 г; тунец в соку 5 шт; рис — много`. `parseHome` раскладывает по продуктам (`HOME_WORDS`, числа словами, кг/г/шт/литры, «много/нет» для запасов), показывает «было → стало», по «Сохранить» пишет через `setHome` и `S.stock`; галочка «свежего, что не назвал, нет» очищает `S.left` недели. Время — `S.homeAt`. Порядок вкладки: «Что дома» → «В магазине» → список с ценами → внизу «Дома — поправить вручную» и «Запасы».
- Порядок недели (5.1): «Что дома» обязателен — пока `S.homeFor` ≠ неделя закупки, вместо списка «Шаг 1» и свёрнутый «Черновик списка». После — `adaptPlan`: излишки дома (белок → обеды/ужины, овощи → вместо «овощей», фрукты → в перекус, гарниры → в обед; по калориям/белку, `convQ`) предлагаются карточкой «Подстроить меню», «Применить» пишет `S.huse[дата|приём]={из:в}` (слой в `dayPlan` после замены белка). То, что и так есть дома (запасы, рис), не заменяется. Бюджет — только итог, без советов.
- 5.8 «Покупки»: у каждой строки списка кнопка «⋯» (`shopLi`, окно `SH`/`sheetHtml`): «Куплено столько» (своё количество, `S.shx[неделя][id]={q}`), «Нет в наличии» (`{none:1}`, строка закрывается; предлагается замена), «Заменить на другое» (пишет `S.wswaps` — замена на всю неделю, количество через `convQ`: белок по белку, остальное по калориям), «Вернуть как в списке». «+ Купил сверх списка» (`shextra`) прибавляет к «Дома». Итог ₫ считается по фактически купленному (`boughtQ`).
- 5.8 свои продукты: `S.custom[id]={n,u,k,p,f,c,pg,sec,price}`; `applyCustom()` (вызывается из `migrate()`) кладёт их в `PR`/`PRICES`, `customHit` узнаёт их в строке «ДОМА: …». Окно «Свой продукт» — из «Купил сверх списка» и «Дома — поправить вручную». Новые поля `S.shx`, `S.custom` — в `def()`.
- 5.8 «Заготовки»: `surplusFor(неделя)` = дома к вторнику + куплено (факт) − нужно (мясо, рыба, тофу, зелень); `bagsNext` раскладывает лишнее по приёмам следующих двух недель пакетами (задача `big:bags2`), остаток — «запас» пакетами ≈230 г (тофу ≈150 г). Зелень (`FRESHG`: водяной шпинат, бок-чой, фасоль) — задача `big:greens`: порции на Вт–Пт в холодильник, дальше — бланшировать и в морозилку. Разовые задачи недели — `PREP_EXTRA`.
- 5.9: «Съел вне плана» (+ у приёма) умеет «Из продуктов дома»: выбираешь продукт и вес → ккал и Б/Ж/У считаются сами, расход пишется в `S.eaten` (`{id,t,p,q}`) и вычитается из «Дома» (`useAfter`, `invFor`); удаление записи возвращает продукт. Пропущенные приёмы (`S.skip`) по плану не списываются. Тофу не бывает самостоятельным поздним перекусом (`tofuveg`/`tofuzuc` без приёмов, в меню заменены), только в блюдах. Фрукты (джекфрут, драконий фрукт и т.п.) не фасуются: в «Раскладке» они в штуках (`FRPIECE`, `pieceText`; упаковка джекфрута ≈ 420 г); `PACKV` = тыква, брокколи.
- 5.10 «Копия в GitHub» (Ещё): «Сохранить копию» кроме файла отправляет данные в приватный репозиторий `godoffear/racion-data` (`latest.json` + `history/racion_ГГГГ-ММ-ДД.json`, GitHub REST API из браузера, `ghPush`/`ghPut`). Токен (fine-grained, только этот репозиторий, Contents: Read and write) хранится только в `localStorage['racion-gh']` на телефоне — не в `S`, не в копии. Репозиторий должен быть приватным (`ghCheck` отказывает для публичного). Если отправка не удалась — флаг `pending`, повтор при следующем открытии. Claude читает `latest.json` из `racion-data` через GitHub MCP (репозиторий нужно подключить в сессию через `add_repo`). Создать репозиторий из сессии нельзя (403), Андрей создаёт сам.
- 5.10.2: 7 окт — лёгкий обед (`leanlunch`) и бургер вместо перекуса (`burger` в `PR`, `nobuy:1` — в списки покупок не попадает; ≈ 850 ккал, Б 50 / Ж 52 / У 45, оценка). Разовая правка данных `seedFix7` (флаг `S.seed3`): снимает старые ручные блюда `S.rec` (7 окт обед, 8 окт ужин, 9 окт обед, 10 окт ужин), привязывает джекфрут 444 г к `S.eaten`, ставит фактический вес чека на строки, отмеченные в магазине до занесения чека, и добавляет 30 яиц (куплены 7 окт 11:40).
- 5.10.3: яйца на 7 окт заданы точно (`eggsFix`, флаг `S.seed4`): 1 варёное + 30 купленных = 31. Ошибка 5.10.2 (было 39): `addHomeQ` считал расход по плану только до начала недели; теперь считает до момента покупки (`un`). «Дома» к вторнику (`invFor`) для докупок посреди недели остаётся приближением: `need` — на всю неделю, включая уже съеденное.
- 5.10.1 автоотправка копии (`ghAuto`): при открытии/возврате в приложение и раз в минуту, если токен подключён и за текущий день приложения (меняется в 2:00, `appNow`) ещё не отправлялось (`racion-gh.autoDay`); после неудачи повтор не чаще раза в 10 минут (`tryAt`). Успешная отправка обновляет `S.lastBackup`. Закрытое приложение само ничего не отправляет (браузер не даёт) — копия уходит при первом открытии нового дня.
- 5.9.5 в «Фасовке" красная строка «Не хватает ≈ X г», если есть меньше, чем нужно по меню (`short`). Остаток дома считается по плану (съедено всё, что в плане после времени записи «Дома»; пропущенные приёмы — нет): если Андрей ел иначе, он обновляет «Дома» (`ДОМА: рыба 470 г`).
- 5.9.4 карточка «Сегодня закупка» (понедельник): крестик и «Уже купил» скрывают её на сегодня (`dismiss`, ключ `shopday`); сама пропадает, когда в списке отмечено ≥ 3 покупок (`boughtFor`).
- 5.9.3 «Фасовка» фасует всё купленное целиком (правило Андрея: купили много — сразу по пакетам в морозилку, чтобы потом не терять качество): мясо, рыба + `PACKV` (тыква, брокколи, капуста, морковь, кабачки, перец, фасоль, грибы; как готовить к морозилке — третий элемент `STORE`); фрукты и тофу не фасуются; хвосты от 30 г тоже пакетом «запас».
- 5.9.2 тофу: Андрей больше его не покупает (в магазине только пачки 300 г). Остаток (≈ 700 г) раскладан по ужинам недели 6–12 окт парами соседних дней (пачка = 150 + 150 г; `chickmushtofu`, `thighgreenstofu`, `chickcabtofu`, `thightomtofu`, `shrimptofu` 100 г), в меню 1–4 тофу нет, тофу-блюда без приёмов (не предлагаются). Тофу исключён из `BAGID` (не фасуется), задача `big:tofu` показывает пачки по 300 г.
- 5.9.1 «Фасовка»: у каждой группы пакетов (например «5 × 250 г») кружки с номерами — тап отмечает готовый пакет, счёт хранится в `S.prepDone[неделя]['pk|продукт|вид|размер']` (число), когда отмечены все — отмечается и сама задача `big:pack` (`pkdone`, `packKeys`).
- 5.8.2 «Заготовки»: вместо расписания пакетов по дням одна задача «Фасовка — что на сколько грамм» (`packModel`, `clusterBags`): по каждому продукту (мясо, рыба, тофу, тыква, брокколи, джекфрут, драконий фрукт, ананас) — «холод. / мороз. / запас», не больше 3 размеров пакета (размер = среднее порций группы). Вечерние напоминания «достань пакеты на завтра» по дням остались.
- 5.8.1: чек GO! 5 окт занесён один раз (`RECEIPT`, `seedReceipt`, флаг `S.seed2`, нужен `S.seed1`): строки списка отмечены купленными с фактическим весом (`S.shx`), покупки не из списка (курица 1,7 кг, водоросли и т.д.) прибавлены к «Дома» (`addHomeQ`); яйца (докупит 40 шт) и ананас (рынок) остаются неотмеченными. Задача «Раскладка покупок — что куда» (`invFor`, `STORE`): морозилка / холодильник / полка, лишнее и чем его заморозить. В `invFor` купленным считается только отмеченное в списке. Новый чек — добавлять так же новым `RECEIPT`.
- 5.11: «Съел вне плана» (+): переключатель «Дома / Вне дома». «Дома» — несколько продуктов из дома (`X.items`, «+ ещё продукт»), под каждым остаток по «Дома» (`homeNow`: запись минус план с момента записи) и красное «дома только N», если ввёл больше; итог ккал и Б/Ж/У суммируется (`xList`, `fillFromProduct`), каждый продукт пишется отдельной строкой в `S.eaten` с общим `id`. «Вне дома» — «Частое», название и ккал вручную. Овощи в меню: общий `veg` убран из блюд (теперь кабачки, перец, капуста, брокколи, фасоль, помидоры, с пометкой «без масла»/«сырыми»), меню 1–4 пересобраны; `veg` остался только в `LEGACY`/старых `OVERRIDES`. Ежедневная сверка: routine `trig_01W3KTXWkwGhujcZskVL2bnu` в 10:37 (Нячанг) читает `racion-data/latest.json` и пишет, что не сходится; утренняя «Сверка» в приложении отклонена Андреем.
- 5.11.1: 7 окт съедено 2 бургера (≈ 1700 ккал) — `OVERRIDES` перекус `burger`×2, ужин курица 100 г + грибы/кабачки/кимчи (`chickmush`), поздний — огурец и помидоры; день заведомо выше нормы (≈ 2700 ккал, белок ≈ 210), завтра без компенсации.
- 5.12 «Покупаю в день»: у продукта признак `daily:1` (пока только багет `bread`) — он не попадает в список «Купить», итог ₫, «Дома», «Фасовку» (как `nobuy`), а в дни, когда он есть в меню, на «Сегодня» висит карточка «Купить свежее сегодня» (`dismiss` ключ `fresh`). Андрей: свежий хлеб покупает сам в день, заранее не закупать. Другие свежие продукты (помидоры, огурцы, зелень) предложены, но не добавлены — только по просьбе Андрея.
- 5.13 «Где покупать»: `S.place[id]` = `'go'|'near'`, по умолчанию (`placeOf`) овощи и фрукты (`sec` veg/fruit) — «у дома, по факту», всё остальное — GO!. Список «Купить» делится на карточку GO! (итог ₫ только по ней, `shopCost`; режим «В магазине» тоже только GO!) и карточку «У дома, по факту» (без цен, с теми же галочками). В окне «⋯» кнопка «Купить у дома / в GO!» (`shplace`). Новое поле `place` в `def()`.
- Вес `S.w` (`[{d,w}]`) может записать приложение Тренер (godoffear/trener, тот же домен) — при возврате в Рацион `S` перечитывается из localStorage. Формат `S.w` не менять.
- Яйца: «вареных N» → `S.boiled` (в холодильнике место под 20 вареных — для заготовок), всего яиц дома = сырые + вареные. «Вареного риса N г» → `S.riceBank` (в сухом эквиваленте).
- Дома: свежее — `S.left[неделя]`, долгохранящееся (`keep:1`: консервы, сухое) — `S.pantry`, помнится между неделями (`homeEntry`/`setHome`). «+ Добавить продукт» — любой продукт справочника. Если дома есть белок, которого нет в меню, — кнопка «Подставить» (`useup` пишет `S.swaps`). Замена белка всегда пересчитывается по количеству белка (`swapQ`: тофу вместо курицы — больше граммов, не больше ×2; граммы ↔ банки).
- Цены: `PRICES` (примерные, часть с sieuthi-go.vn) + правки Андрея по чеку в `S.price`; итог внизу списка, спортпит (`SPORT`) отдельно. Сайт sieuthi-go.vn закрыт сетевой политикой облачной среды — цены только через поиск.
- Напоминания: 7 кнопок «Добавить» в Google Календарь (повторяющиеся события по `REM`), уведомление Андрей ставит сам — Samsung Календарь показывает события Google. Файл `.ics` убран: Samsung терял будильники при импорте.
- Строки из чата Claude: `РАЦИОН: название | ккал | Б | Ж | У | ЧЧ:ММ`, `РАЦИОН-ПЛАН: обед` или любой свободный текст с ккал и Б/Ж/У (`parseFree`) — вставляются через «+» у приёма → «подробнее»; поля формы заполняются сами (`fillFromLine`), их можно поправить перед «OK».
