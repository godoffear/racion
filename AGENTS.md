# Рацион — инструкция для ИИ-агентов (Codex, ChatGPT и др.)

Личное веб-приложение (PWA по питанию) для Андрея. Сайт: https://godoffear.github.io/racion/

**Весь контекст проекта — в этих файлах. Прочитай их полностью до начала работы:**
1. `CLAUDE.md` — главные правила работы, устройство репозитория, норма Андрея, как устроено приложение, блок «Сейчас в работе». Это основная инструкция, следуй ей как своей.
2. `docs/ПАМЯТЬ.md` — подробные описания функций по версиям. Читай только нужные куски.

Коротко (подробности в `CLAUDE.md`):
- Андрей — начинающий разработчик, пишет по-русски (часто голосом). Отвечай по-русски, коротко, по делу, по имени.
- Проект готов и работает. Не «настраивай» среду, не предлагай рефакторинг, не спрашивай, как устроен проект.
- Любое изменение приложения: сначала план пунктами, ждёшь «да». Мелкие исправления ошибок можно сразу — скажи, что исправил.
- Выпуск: правка `src/*` → `python3 src/build.py` → (если трогал меню) `python3 src/menu_calc.py` → `python3 src/check.py` → поднять `APP_VERSION` в `src/app.js` → коммит `index.html` + `src/*` в `main` (постоянное разрешение Андрея) → проверить сборку Pages.
- `index.html` — собранный файл, руками не правь. Ключ хранилища `racion-v3` не менять; новые поля состояния — в `def()` с безопасными значениями.
- Данные Андрея (вес, отметки, «Что дома») живут только в браузере его телефона; копия в приватном репозитории `godoffear/racion-data` (`latest.json`), доступ — только если он выдал.
- После выпуска напиши Андрею, что изменилось, и как обновить: «Ещё → Настройки → Проверить обновление → Обновить».
